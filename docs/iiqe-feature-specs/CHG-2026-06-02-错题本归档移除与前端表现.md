## 考生视角（v1.2）

我在错题本按章/库复习错题。列表告诉我每块还需做对几次、有多少反复错；从刷题返回后，上次做的小节标题旁有亮蓝「上次进行」。刷题时顶栏是「错题本」：掌握进度告诉我差几次可归档；达标点绿条归档，确认后变灰「已归档」，题进「已掌握错题」。若曾掌握的题又错了，标题有「复活题」，错太多还有红条建议深看解析。

---

## 本期范围（In）

### 列表页 §4.2.1

- Tab：`待复习` / `已掌握错题`；七章四库骨架固定
- 待复习四段灰字：`X题需做对3/2/1次`、`X题反复错`（0 也显示，单行 `space-between`）
- 待复习 `共0题` → 右侧方框深蓝勾；已掌握分段无方框
- **上次进行**：`focusSectionId` 匹配小节，标题行 `#00A7E1`「上次进行」（无蓝框底）

### 刷题页 §4.3（仅 `fromErrors` + `sectionId`）

- 掌握进度卡：标题行 + 可选「复活题」角标 + 三点 + 动态灰字
- 底栏互斥：**绿**（点击可归档至已掌握）或 **红**（反复错，不可归档时）
- 归档确认后：**灰**「已归档」+ `archived` + 列表分段迁移 + 居中轻提示
- 两层叠层（无第三层阴影）；底栏文案在可见带内垂直居中
- 非错题本入口：仍写入状态；复活可居中轻提示，不展示掌握区

### 数据 §4.3.3

- 按 **题目 ID** 全局一份（`iiqe-error-book-archive-v2`）
- 反复错（`wrongCount > 5`）同步 `revived`

### Out（仍不在本工单）

- 跨 ≥3 独立 Session 的后端强校验（产品目标见主文档 §1.2；原型以 `masteryProgress≥3` 为准）
- `nextReviewAt` 调度引擎
- 答题记录 / 退出提示弹窗 → **CHG-2026-06-02-B**

## 验收要点（2026-06-03）

- [ ] 列表：四段灰字单行；返回列表见「上次进行」亮蓝；Tab 切换不丢章/库
- [ ] 刷题：仅错题本页有掌握区；连续对 3 次绿条可点归档
- [ ] 归档后：同题灰条「已归档」；待复习不含该题；已掌握分段可见
- [ ] 复活：标题「复活题」角标；不可归档且反复错 → 红条（与绿条不同时）
- [ ] 任意入口再错已归档题：状态复活；非错题本页可轻提示
- [ ] 与 `errorBookArchive.ts` 字段一致
